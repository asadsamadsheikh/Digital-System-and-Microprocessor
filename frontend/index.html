1 · Algorithmic State Machines (ASM)

An ASM is a flowchart-like method to specify the state diagram of a clocked sequential circuit. It is functionally equivalent to a state graph, but it additionally expresses the flow of tasks performed by the datapath under the control of the finite state machine.

The three notations

  • State box — a rectangle. Represents a state. Carries the state name, the state code, and a list of register operations or outputs. One entrance, one exit.
  • Decision box — a diamond. Contains an input condition. One entrance, two exits: 0 (false) and 1 (true).
  • Conditional output box — a rounded (oval) box. Holds output signals asserted only on a particular branch.

Self-loops and Auto Generate

A decision box immediately following a state box may be configured as a self-loop: when the condition is false, the flow returns to the same state (the machine idles there); when it is true, the flow advances to the next state. Use ⚙ Auto Generate to create a chain of N states where each state owns one such decision. Configure the count, the condition text, and the loop behaviour in one dialog.

Construction rule

State S₀
├─ Decision (condition)
│   ├─ 0 → ↺  back to S₀        (self-loop / wait)
│   └─ 1 → next state
└─ ...

2 · Programmable Logic Devices (PLD)

A PLD is a user-configurable integrated circuit capable of implementing arbitrary Boolean functions. Compared to fixed-function ICs, PLDs offer reprogrammability, smaller board space, lower power, and shorter design cycles.

Classification

  • PROM — fixed AND array + programmable OR array.
  • PAL — programmable AND array + fixed OR array.
  • PLA — programmable AND array + programmable OR array. Most flexible; product terms shared across outputs.

PLA structure

INPUT BUFFERS → AND PLANE (programmable)
              → OR PLANE (programmable)
              → Output buffers

Design flow

  1. Write the truth table and minterm list for each function.
  2. Simplify each function — K-map or Quine–McCluskey.
  3. Identify shared product terms across functions to reduce the total number of AND gates.
  4. Draw the PLA table — each row is one product term.
  5. Realize the schematic: cross-points in the AND plane implement each product term; cross-points in the OR plane select which outputs consume it.
